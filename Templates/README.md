# Templates Folder

This folder contains HTML template files organized by niche.

## Structure

```
Templates/
├── barber/          # Barber shop templates
├── tutor/           # Tutor/teaching templates
└── photographer/    # Photography portfolio templates
```

## Template Format

Each template is a **single HTML file** containing:
- Complete HTML structure
- Embedded CSS (in `<style>` tag)
- Embedded JavaScript (in `<script>` tag)
- Placeholder images using data URIs or placeholder services (no external image files needed)

## Usage

These templates are ready to be:
1. Uploaded via the admin template management interface
2. Used by users to create their websites
3. Customized through the GrapesJS editor

## Template Requirements

- Single HTML file per template
- No external dependencies (all CSS/JS inline)
- Placeholder images (no image files required)
- Mobile-responsive design
- Clean, professional design
- Editable elements marked with `data-editable="true"`
